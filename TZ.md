# Социальная боль

В школах не хватает учителей. Поэтому нужна ИИ-модель, которая будет заменять учителя на протяжении всей четверти в школе.

# Этапы выполнеия

1. Разобрать учебно-календарный план за семестр по определенной дисциплине. Выделить темы уроков.
2. Распарсить файл учебника. Сделать доклад каждой темы из предыдущего этапа. Ориентировочное время вычитки доклада 30 минут.
3. Подготовить тестовые задания с заданиями: 70% тестовые задания (4 варианта ответа), 30% задания с открытыми вопросами (ответ вписывает ученик в свободной форме).
4. Оценить выполнение задания.
5. Подготовить презентацию по теме доклада.
6. Озвучить презентацию.

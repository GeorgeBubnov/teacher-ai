# План реализации парсера учебно-календарного плана

## Цель первой версии

Сделать локально разворачиваемый сервис, который принимает файл старого формата Microsoft Word `.doc`, извлекает из него строки учебно-календарного плана и показывает три поля: тему урока, количество часов и компетенции, которые должны быть получены на уроке. Пользователь должен иметь возможность проверить результат, при необходимости исправить его вручную и скачать JSON. Запуск проекта должен выполняться одной командой `docker compose up`. Загруженные файлы и результаты должны переживать перезапуск контейнеров за счет Docker volume.

## Этапы

1. Подготовить контейнер API на Python с FastAPI и системным инструментом `antiword` для чтения бинарного `.doc`.
2. Реализовать проверку расширения файла, сохранение исходного документа и извлечение текста с обработкой ошибок.
3. Реализовать парсер строк: определить заголовок таблицы, найти тему, количество часов и текст компетенций, а неоднозначные места добавить в список предупреждений.
4. Сохранять результат в JSON с идентификатором документа и именем исходного файла.
5. Реализовать React-интерфейс для загрузки файла, отображения результата в таблице и вывода предупреждений.
6. Добавить необязательное ручное редактирование трех полей перед сохранением результата.
7. Добавить API сохранения исправленного результата и скачивание JSON.
8. Подготовить Docker Compose с API, React-интерфейсом и постоянным volume `/data`.
9. Проверить сборку, запуск, загрузку `programma_g-7.doc`, отображение строк и скачивание итогового JSON.

## Критерий готовности MVP

Команда `docker compose up --build` запускает оба сервиса. Пользователь открывает `http://localhost:5173`, выбирает любой файл `.doc`, получает таблицу с полями `topic`, `hours` и `udd`, видит предупреждения парсера, если они есть, и скачивает результат в JSON. После перезапуска контейнеров сохраненный результат остается доступен в Docker volume. Поддержка `.docx`, PDF, авторизация, сложная классификация компетенций и автоматические тесты не входят в первую версию.
